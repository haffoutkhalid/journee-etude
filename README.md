# موقع اليوم الدراسي — مرحلة الدعم المكثف بالمدارس الرائدة

موقع بصفحة واحدة (Flask) يعرض اليوم الدراسي: عدّاد تنازلي، برنامج مفصّل،
بطاقات المتدخلين، واستمارة تسجيل مع رسالة تأكيد فورية.

## التشغيل في PyCharm

1. افتح المجلد `flask_study_day` كمشروع جديد في PyCharm.
2. أنشئ بيئة افتراضية (venv) عبر `File > Settings > Project > Python Interpreter`
   أو ببساطة اترك PyCharm يقترحها تلقائيًا عند فتح المشروع.
3. افتح الطرفية (Terminal) داخل PyCharm وثبّت المتطلبات:

   ```bash
   pip install -r requirements.txt
   ```

4. شغّل الملف `app.py` (زر Run، أو من الطرفية: `python app.py`).
5. افتح المتصفح على: `http://127.0.0.1:5000`

## فضاء الإدارة (لائحة الحضور)

أسفل استمارة التسجيل في الصفحة الرئيسية، يوجد رابط **"فضاء الإدارة — لائحة الحضور"**
يؤدي إلى `/admin`، محمي بكلمة سر (الصفحة `/admin/login`).

- كلمة السر الافتراضية: `riyada2026` — **غيّرها قبل أي استعمال فعلي** عبر متغير
  البيئة `ADMIN_PASSWORD` (وكذلك `SECRET_KEY` لمفتاح الجلسة).
- تعرض لوحة الإدارة: العدد الإجمالي للمسجَّلين، توزيعهم حسب الورشة، وجدول
  كامل بجميع البيانات، مع زر لتحميل القائمة كملف CSV.
- مثال لتشغيل المشروع بكلمة سر مخصصة:

  ```bash
  set ADMIN_PASSWORD=كلمة-سر-قوية   (على Windows)
  export ADMIN_PASSWORD="كلمة-سر-قوية"   (على macOS/Linux)
  python app.py
  ```

## التخصيص

- **تاريخ الحدث**: غيّر قيمة `EVENT_DATE_ISO` في `app.py` (الصيغة: `YYYY-MM-DDTHH:MM:SS`).
- **البرنامج والمتدخلون**: عدّل لوائح `PROGRAM` و `SPEAKERS` و `WORKSHOPS` في `app.py`.
- **التسجيلات**: تُحفظ كل استمارة في ملف `inscriptions.csv` الذي يُنشأ تلقائيًا
  بجانب `app.py` عند أول تسجيل (قابل للفتح مباشرة في Excel).
